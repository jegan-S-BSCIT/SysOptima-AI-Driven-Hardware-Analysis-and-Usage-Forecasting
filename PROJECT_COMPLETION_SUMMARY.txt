ALGORITHM EXPLANATION
================================================================================

SCORING ALGORITHM:

Component Score = Normalized Benchmark Result (0-100)
  - Each component measured in different units
  - Results normalized to 0-100 scale
  - Based on real-world reference values

COMPARISON ALGORITHM:

Difference % = ((Local_Score - Reference_Score) / Reference_Score) * 100

Status Classification:
  if Difference > +10%: "ABOVE AVERAGE"
  elif Difference > -10%: "AVERAGE"
  else: "BELOW AVERAGE"

BOTTLENECK DETECTION:

Bottleneck = Component with MIN(Score)
  - Simple minimum function
  - Identifies weakest component
  - Explains performance limitation

HEALTH CLASSIFICATION:

Overall_Score = Mean(CPU_Score, RAM_Score, GPU_Score, Storage_Score)

Classification:
  if Overall_Score >= 85: "Excellent"
  elif Overall_Score >= 70: "Good"
  elif Overall_Score >= 50: "Average"
  elif Overall_Score >= 30: "Below Average"
  else: "Poor"
