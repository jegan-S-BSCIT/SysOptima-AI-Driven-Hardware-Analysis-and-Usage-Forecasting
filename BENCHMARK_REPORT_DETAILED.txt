Impact on System:          SIGNIFICANT

BOTTLENECK EXPLANATION:
RAM is your system's primary performance bottleneck due to the extremely high usage
(87.1%) and limited capacity (11.7GB). This creates several problems:

1. Limited Multitasking
   - Only 1.3 GB available for new applications
   - System must use slow virtual memory (disk swapping)
   - This causes noticeable slowdowns when opening new programs

2. Responsiveness Issues
   - When RAM fills up, system relies on slower storage
   - This makes the entire system feel sluggish
   - Background tasks become noticeably slower

3. Application Performance
   - Heavy applications (Chrome, VS Code, Gaming) suffer first
   - Multiple open applications compound the problem
   - Professional workflows are severely impacted

WHY RAM IS THE BOTTLENECK:
While your CPU (79.8) and Storage (100.0) are excellent, and GPU (85.0) is very
good, the RAM bottleneck prevents these from reaching their potential. Think of
it like a highway with excellent cars (CPU, GPU) trying to cross a narrow bridge
(RAM). The bridge is the limiting factor.

CASCADING EFFECTS:
  RAM Bottleneck → System uses Virtual Memory (disk swapping)
                → Storage must handle extra I/O
                → CPU waits for memory operations
                → Overall system slowdown
                → User experience degradation
